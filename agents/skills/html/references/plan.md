# Plan profile

Use this profile for a proposed or agreed course of action.

Before writing, confirm that the source inventory includes the problem and background, intended outcome, scope, restrictions, ordered and parallel work, decisions and reasons, rejected options, dependencies, owners, dates, statuses, assumptions, risks, open questions, files, commands, and completion checks.

Use `examples/plan.html` and the section order it demonstrates. Drop every section the plan does not support.

Each ordered step states what it changes and includes its stated rules, dependencies, completion check, and undo procedure. Give each step an `id` so cross-references become links.
