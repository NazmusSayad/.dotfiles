Write every piece of text, including headings and labels, in strict ASD-STE100 Simplified Technical English, with no jargon.

Write for the reader's goal and level. Include only what they need to understand, decide, or act. Lead with what matters most to them, and give context before detail. If a technical term is unavoidable, explain it in plain words the first time you use it.

Every sentence must help the reader. Delete any sentence that only introduces, repeats, or sums up what is already there.
