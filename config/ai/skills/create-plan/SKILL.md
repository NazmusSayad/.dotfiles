## Plan Output

- Do not include assumptions, guesses, open questions, or decisions to be made. Discuss them with the user before writing the final plan.

## Interactions

- Do not make changes while creating a plan.
- Ask questions when the request is unclear. Use the question tool when available. Give useful options.
