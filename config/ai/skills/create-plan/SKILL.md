## Planning

- Find facts yourself instead of asking the user.
- Ask independent questions together. Wait for the user's answers before asking dependent questions.

## Questions

- Ask the user only for decisions.
- Ask questions when the request is unclear.
- Use the question tool when available. Give useful options and a recommended option.

## Final Plan Output

- Write the final plan only after all decisions are settled with the user. Do not include assumptions, guesses, open questions, or decisions to be made.
